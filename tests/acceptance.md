## 测试总结

- **通过**：功能测试 12/12、权限测试 7/7、界面测试 8/8、恢复测试 6/6、自主功能测试 5/5
- **环境问题记录**：
  1. Ghost 本地开发模式邮件配置为 Direct/SMTP(1025)，无 SMTP 服务器时评论提交会因邮件通知失败返回 500。解决方案：启动测试 SMTP 服务器（scripts/smtp-test-server.js）监听 1025 端口。
  2. Ghost 导入器对已存在内容会重复创建（slug 冲突时加 -2 后缀），需手动清理重复内容。
  3. Git HTTPS push 在 Windows 上可能遇到 SSL 证书验证失败，解决方案：git config --global http.sslVerify false（仅本地实验环境）。
- **交付物**：可运行 Ghost 博客、自定义主题 oss-blog-theme、相关文章推荐自主功能、脱敏备份、完整 Git 过程证据（分支/PR/Review/tag）、README/NOTICE/测试文档。
