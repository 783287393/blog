# Live Demo 演示脚本 — 实验01 开源个人博客系统

预计时长：8 分钟
演示环境：本地 Ghost 6.63.0 (http://localhost:2368/)

---

## 1. 开场介绍（30 秒）

> "本次实验基于 Ghost 6.63.0 二次开发了一个个人博客系统，包含自定义主题、会员评论、全站搜索，以及一个自主功能——相关文章推荐。代码已托管在 GitHub，包含完整的 Git 分支、PR、Review 和 tag 过程证据。"

展示：GitHub 仓库主页（https://github.com/783287393/blog），简要说明目录结构。

---

## 2. 前台展示（2 分钟）

打开 http://localhost:2368/

**讲解要点：**
1. **首页文章列表**：展示文章卡片，每张卡片包含封面图、标签、标题、摘要、作者、日期、**阅读时长**（主题修改点 1）
2. **导航栏标签入口**：导航菜单后显示主要标签快捷链接（News、开源软件、软件工程、博客开发），点击可跳转到对应标签页（主题修改点 2）
3. **全站搜索**：点击导航栏搜索图标，输入中文关键词（如"开源"），展示搜索结果；输入不存在的词，展示无结果提示

**操作：**
- 点击一个标签（如"开源软件"），展示标签页文章列表
- 点击搜索图标，输入"Ghost"，展示搜索结果，点击跳转到文章

## 3. 文章详情页（2 分钟）

打开任意一篇文章（如"为什么选择 Ghost 作为个人博客平台"）

**讲解要点：**
1. **全标签显示**：文章标题上方显示该文章的全部标签（不只主标签）（主题修改点 3）
2. **元数据**：作者头像、姓名、发布日期、阅读时长
3. **评论区**：滚动到评论区，展示会员甲和会员乙的评论；说明会员登录后可评论（comments_enabled = all）
4. **自主功能——相关文章推荐**：滚动到页面底部，展示「相关文章」区，说明这是按文章主标签匹配的同主题文章推荐（自主功能）

**操作：**
- 展示评论区已有评论
- 展示底部「相关文章」区，说明推荐逻辑（同标签优先、排除当前文章、最多4篇、无相关时回退最新文章）

## 4. 管理后台（2 分钟）

打开 http://localhost:2368/ghost，用 admin@blog.local / Blog@2026admin 登录

**讲解要点：**
1. **仪表盘（Analytics）**：展示文章浏览统计
2. **文章管理（Posts）**：展示已发布的文章列表（8+ 篇），说明可新建/编辑/删除文章
3. **会员管理（Members）**：展示会员甲、会员乙两个会员账号，说明可添加/编辑会员，支持 Impersonate 模拟登录
4. **评论管理（Comments）**：展示会员提交的评论，说明管理员可审核/删除评论
5. **主题设置（Settings → Design）**：展示当前激活的自定义主题 oss-blog-theme，说明可切换主题、自定义颜色/字体/布局

---

## 5. 自主功能技术实现（1 分钟）

**讲解要点：**
- **功能名称**：相关文章推荐（Related Posts）
- **用户价值**：读者读完一篇文章后，可看到同主题延伸阅读，提高站内浏览深度
- **数据来源**：Ghost Content API（主题内 `{{#get "posts"}}`，按 `tag:{{primary_tag.slug}}` 过滤）
- **实现位置**：`theme/oss-blog-theme/post.hbs` 底部
- **失败状态处理**：无同标签文章时回退到最新文章推荐；均无时隐藏区块
- **隐私影响**：无（纯服务端渲染，不收集用户行为）

展示：用编辑器打开 `theme/oss-blog-theme/post.hbs`，指向相关文章推荐的代码段。

## 7. 备份与恢复（30 秒）

**讲解要点：**
1. **导出**：Settings → Advanced → Import/Export → Export，可导出全部内容为 JSON
2. **导入**：同页面 Import，可从 JSON 恢复内容
3. **脱敏备份**：`docs/backup/ghost-export-sanitized.json`，已移除 private key（ghost_private_key、members_private_key）和用户密码哈希，可安全提交到 Git
4. **主题备份**：`theme/oss-blog-theme.zip`，可直接上传到新 Ghost 实例激活
